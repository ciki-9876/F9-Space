# 问题(尚无完整结论)

我想做 OPC（一人公司），最理想方向是独立游戏开发。AI 放大了个人能力，但——**我的护城河到底在哪？**

核心矛盾：AI 让每个人都能做更多，那"每个人都能做"的事如何变成我的竞争优势？

# 目前能拼出的方向

| 方向 | 来源 | 我的判断 |
|---|---|---|
| 封装领域经验为 Agent 模板并分发 | Anthropic 金融 Agent 开源案例 | 有价值但护城河存疑——别人也能 fork |
| 护城河在"持续迭代的领域判断力"而非产品本身 | 同上案例反思 | 这意味着商业模式更接近咨询/陪跑？ |
| 独立游戏 = 审美 × 创意 × 游戏理解力 | 自我评估 | 这三项是我的天赋叠加，AI 能放大执行力但替代不了品味 |
| 信息差三层模型：搬运工→创作者→IP与系统 | 公众号文章（未入库） | 低优先级备选路径——卖信息/知识付费，非首选方向但可作为过渡期变现手段 |
| "离问题最近的人做工具" | Anthropic 销售案例 | 我最懂游戏体验和玩家心理，AI 帮我补技术短板 |

# 尚未回答的子问题

- 独立游戏开发的护城河是"品味"还是"产量"还是"IP 积累"？
- AI 时代独立游戏的竞争格局会怎么变？（人人都能做游戏后，什么会稀缺？）
- "卖模板"vs"卖咨询/陪跑"vs"卖作品"——哪种 OPC 模式最适合我的能力组合？
- 有没有可能先靠"AI + 运营经验"做咨询挣第一桶金，再 fund 独立游戏开发？
- 家庭约束（一岁半小孩）下，OPC 的现实启动路径是什么？全职切换还是渐进式？

# 我的能力盘点(做 OPC 可调用的)

- 审美 + 文字功底 + 创意
- 游戏天才（快速理解任何游戏 + 超常发挥）
- 游戏行业从业经验（运营视角）
- SaaS 产品经理经验
- AI 工具熟练度（正在快速积累）
- 理解玩家心理和内容生态
