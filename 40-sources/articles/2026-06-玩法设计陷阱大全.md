# 一句话摘要

游戏玩法设计的"反模式字典"——系统性列举让游戏不好玩的常见陷阱（7大类），每个陷阱配有"如何检查"+"解决方案"。核心原则：了解失败比追求成功更重要，"成功的游戏各具特色，失败的例子往往落入相似的陷阱"。

# 关键观点（7大类陷阱框架）

## 1. 玩起来不像游戏（不符合基本期待）
- 玩家基本期待 = 掌控感 + 做选择 + 实现目标 + 失败可归因 + 沉浸心流
- **目标与选择对应不上**：玩家不知道哪些行动影响哪些结果
- **重要元素不可互动**：占注意力的东西玩家碰不到→挫败
- **机制冲突**：同时要求快速决策和深思熟虑→注意力撕裂
- **违反直觉**：设计师太熟悉自己的设计，忘了新玩家视角
- **缺少短期挑战**：没有即时反馈的重复操作→无聊

## 2. 选择不有趣（Sid Meier："游戏是一系列有趣的选择"）
- **明显最优解**：看似多选项实质单一→策略深度崩塌
- **选择间缺乏张力**：不需要取舍→平淡。好设计 = 共用限制/互斥关系/正负双面效果
- **目标间缺乏张力**：不同选择对终极目标影响相似→做什么都差不多
- **重玩性低**：变化不够丰富（外部变化少/后果单一/中间目标少）
- **目标孤岛**：某目标只有一条路径可达成且不与其他目标关联→浪费注意力
- **选择越来越无效**：积累型机制让后期选择影响递减→无力感

## 3. 节奏失调
- **节奏缺乏变化**：注意力 = 好奇 + 紧张，无变化则注意力流失

## 通用原则(任何游戏设计review场景都适用)

| 原则 | 落地动作 |
|---|---|
| 避坑 > 追求完美 | 设计完成后用本清单逐条检查是否踩坑，而非追求每条都完美 |
| 每个目标必须有可影响它的选择 | 检查：玩家能做什么来影响这个目标？如果答不上来=问题 |
| 选择必须有张力 | 检查：玩家做这个选择时需要放弃什么？如果不需要放弃=无趣 |
| 短期挑战维持注意力 | 即使长期目标需要时间，每分钟都要有小挑战/小反馈 |
| 节奏必须有变化 | 好奇+紧张的交替才能维持注意力 |

## 场景限定技巧(仅当触发条件匹配时调用)

| 触发条件 | 可调用的技巧 | 出处 |
|---|---|---|
| Playtest 后玩家反馈"无聊" | 检查：是否有明显最优解？选择间是否有张力？节奏是否有变化？ | 陷阱2+3 |
| 玩家反馈"不知道该干什么" | 检查：目标与选择是否对应？是否有足够引导？ | 陷阱1 |
| 玩家反馈"太复杂了" | 检查：是否有机制冲突？是否违反直觉？ | 陷阱1 |
| 设计新机制时自检 | 问：它是否支持统一体验？是否与现有机制冲突？是否直觉可理解？ | 陷阱1 全段 |
| 设计经济/养成系统 | 检查：选择是否越来越无效？是否需要消耗/消除机制保持选择有效性？ | 陷阱2末段 |

## 不适用场景

- 创作初始灵感阶段（不要被避坑心态束缚创意）
- 超休闲游戏（文中注明：不需要节奏变化等复杂设计）
- 叙事/体验型游戏（本文侧重"选择+挑战"型玩法）
