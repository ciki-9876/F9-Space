# 工具列表

## LLM 驱动的知识库系统

- **LLM Wiki** — Karpathy "LLM Wiki"理念的开源桌面应用实现;文档丢进去自动生成结构化 Wiki 页面 + 交叉引用 + 知识图谱。**11.1k stars / 1.4k forks**（2026-06-11 GitHub 实测） #开源 #桌面应用 #知识图谱
  - URL: https://github.com/nashsu/llm_wiki ✅ 已核实
  - 来源: 微信公众号"逛逛 GitHub"(2026-06)
  - ⚠️ **使用限制**: 这是 Tauri 跨平台桌面应用,无法在 Titan K8s 沙箱中运行。对我的价值定位是**架构参考**而非可安装工具——两步录入 prompt 设计、4 维关联模型算法、知识缺口检测逻辑可参考其源码移植为沙箱内 Python 脚本
  - 核心能力:
    - **两步链式录入**: LLM 先分析(提取实体/概念/关联/矛盾) → 再生成 Wiki 页面,质量高于一步到位
    - **知识图谱可视化**: 四维关联度(直接链接×3 + 来源重叠×4 + Adamic-Adar×1.5 + 类型亲和×1),Louvain 社区发现
    - **图谱洞察**: 自动发现"意外关联"(跨社区连接)和"知识缺口"(孤立页面/稀疏社区)
    - **深度研究**: 发现缺口后自动生成搜索词 → Tavily API 搜索 → 综合写入 Wiki → 触发录入流程
    - **Chrome 剪藏**: Readability.js 去噪 + Turndown.js 转 Markdown → 自动发送到应用触发录入
    - **向量搜索**: LanceDB 近似最近邻 + 2 跳图遍历,召回率 58.2% → 71.4%
    - **Obsidian 兼容**: 生成目录就是标准 Obsidian Vault
  - 支持模型: OpenAI / Anthropic / Google / Ollama / 自定义接口
  - 支持格式: PDF / DOCX / PPTX / Excel / 图片 / 音视频 / Markdown

# 场景 → 工具匹配(AI 检索入口)

> 用户描述出以下场景时,AI 应主动推荐对应工具。

| 用户场景描述 | 推荐工具 | 推荐理由 |
|---|---|---|
| "想把知识库从手动维护升级为自动化" / "Claude Code 每次要读规则太慢" | **LLM Wiki** | 自动录入+自动建立交叉引用+增量缓存,比手动 Claude Code 效率高 |
| "想看我的知识之间有什么隐藏关联" / "知识图谱" | **LLM Wiki** | 四维关联引擎 + 可视化 + 自动发现意外关联 |
| "想知道我的知识库有什么缺口" / "哪些方向我还没覆盖" | **LLM Wiki** | 图谱洞察自动检测孤立节点/稀疏社区/桥接节点 |
| "看到好文章想一键存进知识库" / "剪藏" | **LLM Wiki Chrome 扩展** | 一键去噪转 Markdown + 自动触发录入流程 |
| "想做类似的知识库产品" / "参考知识库系统架构" | **LLM Wiki**(参考架构) | 两步录入 + 图谱引擎 + 深度研究 + 增量缓存的设计模式值得参考 |

# 对我当前知识库系统的设计启发

> 即使不迁移到 LLM Wiki,以下设计思路可用于优化我现有的 zhishiku + Claude Code 方案。

| LLM Wiki 设计 | 我当前方案 | 可优化方向 |
|---|---|---|
| 知识图谱 + 缺口检测 | 无(靠 link 手动关联) | 未来可做:定期让 AI 扫描所有笔记的 link 关系,输出"孤立笔记""缺口主题"报告 |
| 自动深度研究填补缺口 | resolved: false insight(手动跟踪) | 未来可做:对 resolved:false 的 insight 自动联网搜索相关资料 |
| Chrome 剪藏 → 自动入库 | agent-browser 手动抓取 | 效率提升方向:如果有浏览器扩展直接推 Markdown 到 00-inbox/ |
| 来源重叠关联引擎 | 手动写 related/link | 未来可做:AI 录入时自动扫描已有笔记寻找关联,而非只靠人工标注 |
| SHA256 增量缓存 | 无(每次全读) | 文件量大后可考虑 |
| purpose.md(KB 方向) | CLAUDE.md + 库主人是谁 | ✓ 已覆盖,且更详细 |
| 两步录入(分析→生成) | 4 步审稿流程 | ✓ 已覆盖,且加入了人工校准环节,质量更高 |
