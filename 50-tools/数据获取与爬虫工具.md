# 工具列表

## OpenCLI — 将任意网站变成命令行工具调用

- **定位**：通过 Chrome 扩展 + CDP 协议，免登录下载 79+ 平台的内容（文章→markdown+图片、视频、评论等）
- URL: https://github.com/jackwener/opencli
- 来源文章: https://mp.weixin.qq.com/s/9yGV9nrs5Pd6hIi7_bjaWQ
- 许可证：开源免费
- 核心能力：
  - 公众号文章→markdown + 图片（保持图文对应关系）
  - 支持平台：微信公众号、小红书、B站、知乎、雪球、YouTube 等 79+
  - 利用浏览器已有 cookie 免重复登录
  - 视频下载（依赖 yt-download）
  - 评论区数据获取
- 技术架构（可复用的设计模式）：
  - 终端命令 → CLI → 本地守护进程(Daemon) → WebSocket → Chrome 扩展(Browser Bridge) → 浏览器标签页 → 结果返回
  - 底层协议：Chrome DevTools Protocol (CDP)——远程控制浏览器、操作 DOM、拦截网络请求、执行脚本
  - 非传统 HTML 爬虫，而是"操控真实浏览器"模式
- 安装方式：`npm install -g @jackwener/opencli` + Chrome 扩展 + `npx skills add jackwener/opencli`（Claude Code skill）
- ⚠️ **使用限制**：需要本地 Chrome 浏览器 + 扩展安装，Titan K8s 沙箱中能否运行未验证。作为 Claude Code skill 设计，与 Titan 平台的兼容性待测。
- **对我的价值定位**：技术架构参考。当我需要开发有爬虫/数据获取能力的产品时，"CDP + Browser Bridge + WebSocket"这套模式比传统 Playwright 模拟更高效，可作为技术方案参考。

## Firecrawl — AI 友好的通用网站爬取 API

- **定位**：把任意网站转为 LLM 可用的 markdown 或结构化数据，专为 AI 应用设计
- **132k stars**（2026-06-12 GitHub 实测），v2.10（2026-05-15 发布），非常活跃
- URL: https://github.com/mendableai/firecrawl ✅ 已核实
- 许可证：AGPL-3.0（SDK 为 MIT）
- 核心能力：
  - 单页爬取（scrape）：任意 URL → 干净 markdown，自动处理 JS 渲染
  - 批量爬取（crawl）：整站递归抓取，支持深度/路径过滤
  - 结构化提取（extract）：用 AI + schema 从网页中提取结构化数据（文章/产品/价格）
  - 智能搜索（search）：在网站内搜索相关内容片段
  - 网站地图（map）：发现所有 URL
  - 截图功能
- 技术架构：
  - 底层引擎：Puppeteer/Playwright + 反爬绕过
  - 内容处理：HTML → Markdown 转换 + 内容清理 + AI 数据提取
  - SDK：官方支持 JS/Python，社区支持 Go/Rust/Java
  - 集成：LangChain / LlamaIndex 内置支持
- 定价：免费层可覆盖 MVP 验证，按量付费
- **与 OpenCLI 的区别**：
  - OpenCLI = 社媒平台专用，利用浏览器 cookie 免登录，输出图文分离
  - Firecrawl = 通用网站，API 调用无需浏览器，输出 LLM 友好格式
- **对我的价值**：
  - 当我做需要"把网上信息变成 AI 可用数据"的产品时，Firecrawl 是成熟的基础设施选择
  - RAG 知识库构建、竞品监控、内容聚合等场景的首选工具
  - 未来知识库如需自动化录入外部内容，可作为数据源

# 场景 → 工具匹配(AI 检索入口)

| 用户场景描述 | 推荐工具 | 推荐理由 |
|---|---|---|
| "需要开发一款能获取社媒平台数据的产品" / "爬虫技术方案" | **OpenCLI**（参考架构） | CDP + Browser Bridge 模式比 Playwright 更高效，免登录 |
| "想批量下载公众号文章存到知识库" / "把文章转成 markdown" | **OpenCLI** | 直接输出 markdown + 图片，适合知识库录入 |
| "怎么绕过平台登录获取数据" | **OpenCLI 的 cookie 复用模式** | 读取浏览器已有 cookie，不需要模拟登录流程 |
| "把任意网站内容转成 AI 可用的数据" / "给 RAG 系统喂数据" | **Firecrawl** | 132k stars 的成熟 API，直接输出干净 markdown，处理 JS 渲染 |
| "从网站批量提取结构化信息（产品/价格/文章）" | **Firecrawl extract** | AI + schema 提取，不用写解析规则 |
| "做竞品监控 / 内容聚合类产品" | **Firecrawl crawl + extract** | 整站递归 + 结构化提取，适合持续监控场景 |
| "给 LangChain / LlamaIndex 项目接数据源" | **Firecrawl** | 官方内置集成，即插即用 |
