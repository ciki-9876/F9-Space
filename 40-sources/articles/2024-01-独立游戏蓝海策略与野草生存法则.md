# 一句话摘要

两次资金链断裂但没借钱/没卖房/没裁员的独立游戏团队分享生存方法论：蓝海策略（不与大厂争20%红海玩家）+ 情感化设计×包容性设计 + 野草/病毒生存法则（小、韧、独特）。核心：独立游戏的"爱"要爱具体的人，不爱抽象的概念。

# 关键观点

## 蓝海策略：不跟大厂抢红海
- **红海**=枪车球+青春期男性玩家（20%群体榨80%利润），需要心智占领（同伴效应/让步效应/损失厌恶），需要烧钱买量
- **蓝海**=红海之外的一切。"盲人玩家的1块钱比明眼人便宜吗？"——《听游江湖》4年12万用户，高峰21.8万人次/天
- 独立游戏之所以叫独立游戏，就是独特、小众、低成本、比拼创意

## 情感化设计：爱具体的人
- 不要居高临下教育玩家，要从玩家真实感受出发
- "如果玩家不喜欢玩你的游戏，你什么意义都传达不了"
- 案例：熊熊诊所（病童游戏）——把冰冷的CT机变成想帮忙的朋友，把"癌症"变成具象的"痛痛虫"。孩子不害怕了，才能配合治疗
- **"用爱发电，爱谁？"** 爱具体的人/玩家/作品=对；爱"3A"/爱"国产之光"=爱抽象概念=危险

## 包容性设计：门槛低到尘埃里
- "玩家喜欢的不是挑战难以理解，而是掌控复杂与困难"
- 魂系游戏虽难但理解层面极清晰（贪刀=死，不贪=活）——退休阿姨也能坚持一年打通
- **核心交互最多4个键**。《越过重山》鼠标1键或键盘3键完成所有操作，400MB，常年9.9元
- "给我一个支点我可以撬起地球"——游戏可以很复杂，但支点（入门门槛）不能丢

## 野草/病毒生存法则
- 大厂=狮子（需大量食物，立项1000万起，一年搞KPI和立项会议）
- 独立=野草（烧不尽春风吹又生，不需要大量资源就能存活）
- **开罗游戏**：同一套美术素材做十几款不同模拟器，每款都独特，一说"模拟器"玩家第一个想到它
- **ZUN/东方Project**：一个人喝啤酒弹琴随便搞，画立绘从头往脚画（先画最特色的部分），社区帮做同人。不靠游戏赚钱，参加活动就有生活费
- **荒木/JoJo**：独特风格本身就是产品。"JoJo是什么风格？JoJo就是JoJo风格"

## "3A"不是质量保证
- 3A=工业模式，国产之光=实质体验。两者不等号
- "什么最痛苦？烂尾楼才最痛苦。"——花小钱做小制作玩家也买账，关键是用心+完成
- 与其追求"3A"不如追求"完成"

# 我有疑问 / 不认同的

> 以下由 AI 基于福九处境预生成的反方种子，待审核：

- **"蓝海"听起来美好，但蓝海的问题是"找不到用户在哪"**：红海虽然卷，但用户集中、分发渠道清晰（Steam射击类标签、TapTap热门）。蓝海（如盲人游戏、病童游戏）的用户分散、获客路径不明确。12万用户的《听游江湖》是特例——多数蓝海产品连1万用户都找不到。→ **调用规则**：蓝海方向的前提是"你能找到这群人在哪聚集"。选蓝海时必须同时想清楚分发渠道（社群？医院合作？无障碍组织？），否则做出来了没人知道。

## 通用原则(独立游戏开发全场景适用)

| 原则 | 落地动作 |
|---|---|
| 蓝海 > 红海 | 不要做大厂在做的品类。找大厂看不上/做不了的细分领域 |
| 爱具体的人 | 选方向时问：我为谁做？这群人在哪？他们现在怎么凑合解决这个需求？ |
| 门槛低到尘埃里 | 核心交互最多4键。第一分钟就让玩家知道"怎么玩"和"赢了什么感觉" |
| 完成 > 完美 | 烂尾楼最痛苦。花小钱做小制作也行，关键是完成并发布 |
| 野草生存 | 保持小、保持韧、保持独特风格。不追求大量资源，追求"烧不尽" |
| 开罗模式可参考 | 同一套核心资产/风格复用到多款游戏=降低成本+建立品牌辨识度 |

## 场景限定技巧(仅当触发条件匹配时调用)

| 触发条件 | 可调用的技巧 | 出处 |
|---|---|---|
| 选独立游戏方向 | 蓝海策略：不做大厂在做的品类 + "爱谁"三问（为谁/在哪/怎么凑合解决） | 蓝海段 |
| 设计游戏的入门体验 | 包容性设计：最多4键、第一分钟搞懂、难而清晰（魂系≠晦涩） | 包容性段 |
| 设计功能游戏/严肃游戏 | 情感化设计：从用户感受出发，不居高临下教育。"不好玩=什么意义都传达不了" | 情感化段 |
| 完美主义想做大作 | "什么最痛苦？烂尾楼。" + 野草法则：保持小+完成 > 追求大+烂尾 | 3A段+野草段 |
| 思考长期生存模式 | 开罗模式（复用资产多款游戏）/ ZUN模式（一人+社区）/ 荒木模式（风格即品牌） | 野草段 |

## 不适用场景

- 做 SaaS/工具类 OPC 时（本文专精于游戏行业逻辑）
- 已经在大厂做大项目时（本文是独立/小团队视角）
