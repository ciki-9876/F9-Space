# 主题定义

覆盖游戏设计全链路：体验理论 → 玩法设计 → 关卡设计 → 数值设计 → 叙事设计 → 用户研究 → 发行分发 → 独立游戏生存。适用于：独立游戏开发、游戏策划岗位、UGC编辑器产品运营。

# 核心框架（跨 source 综合）

## 设计哲学层

| 原则 | 来源 | 一句话 |
|---|---|---|
| 喜欢 = 熟悉 + 意外 | 游戏体验设计 | 惊喜公式：在熟悉基础上制造意外 |
| 游戏 = 有意义感的选择 | 游戏体验设计 | 对席德梅尔的迭代——不是"有意义"而是"有意义**感**" |
| 交互 > 被动 | 游戏体验设计 | 主动获取的反馈大脑更在意，游戏比电影深刻就因为交互 |
| 峰终定律 | CE五大技巧 + 体验设计 | 玩家记住的是高峰时刻和结尾，不是过程时长 |
| 验证"记忆点"而非打分 | CE五大技巧 | 问"脑海里留下什么"而非"满不满意" |
| 让工作感觉像玩耍 | Nick Yee | 游戏成功=最小化倦怠感，让玩家不知不觉中"工作" |
| 节奏三要素 | 拳皇98制作人曹楠 | 节奏=时间轴上的（横轴：时间长短）×（纵轴：可量化事件）×（函数：波动曲线）。好莱坞三段式：开场激烈→中段对抗→结尾升华 |

# 设计检查清单（做游戏时 AI 应主动提醒）

## 创作阶段（靠灵感，不要被束缚）
- 用"翻转固定印象"+"汇合已知事物"想创意
- 从短篇/小原型练起，不追求第一次就做大
- "爱谁？"——爱具体的人，不爱抽象概念

## Review 阶段（靠清单，系统检查）
- [ ] 玩法陷阱检查：是否有明显最优解？选择间是否有张力？节奏是否变化？
- [ ] 核心交互是否最多4键？第一分钟能否搞懂"怎么玩"？
- [ ] 体验公式检查："熟悉+意外"是否平衡？高峰时刻在哪？结尾是否有力？
- [ ] 是否让玩家"主动"而非"被动"？纯播片是否过多？
- [ ] 倦怠风险：重复性机制是否会让玩家觉得是"chore"？

## 上线前（发行/分发）
- [ ] Steam商店页是否准备好？（预告片展示玩法/截图展示UI/标签精准）
- [ ] 愿望单是否开始积累？
- [ ] "我在做什么游戏？为谁做？"——答案是否清晰？

# 爆款游戏拆解灵感（零散记录，攒够3篇后建专题）

## 《寻道大千》（微信小游戏，放置RPG，2023年畅销榜霸榜半年）
- 来源：三七互娱微信公开课 Pro 2024 演讲
- **世界观不靠剧情/对话/文字传达，靠玩法引导和副本**——对独立开发者的启发：如果做不了大量文本叙事，可以用"玩法本身就是世界观"降低文本需求
- **渡劫=整体外显变化=阶段性目标**——不做100套部件换装（美术量大），而是每个大节点整体形象变一次。养成进度极其可见+资产需求可控
- URL: https://mp.weixin.qq.com/s/t__w46N8CLPcLiaDdl-ObA

## 《冲呀！饼干人：王国》（模拟经营+卡牌，Devsisters韩国）
- 来源：GameRes/知乎拆解文（2023-12）
- **IP统一美术风格=品牌辨识度**：所有游戏（跑酷→王国→OvenBreak）共用角色/UI/风格，玩家一眼认出。与开罗模式（"同一套皮多款游戏"）异曲同工——对OPC独立开发者的启发：建立自己的"视觉签名"并跨作品复用
- **模拟经营+卡牌的双循环**：经营产资源→养角色→角色推进度→解锁新经营。短线=战斗（即时反馈），长线=经营（持续目标）。如果做休闲/放置/模拟经营+养成，这种双循环是成熟参考
- **成长限制4维度**：等级/城堡等级/体力/时间——多维度限制防止单一维度突破导致失衡
- URL: https://mp.weixin.qq.com/s/tHu-t4_Nt2KMA94G1U4zPA

## 《Monopoly Go!》（大富翁休闲，7个月破10亿美元，Scopely美国）
- 来源：罗斯基翻译 Scopely CMO 文章（2023-12）
- **游戏内外社交循环设计**：贴纸收集活动→引导到500万人Facebook群交换→回到游戏与新朋友互动。社交渠道不是单向广播，是双向互动论坛。效果：游戏时间+100%，朋友邀请安装+74%
- **从立项就植入社交**：不是发布后补社交功能，而是开发最早期就以"社交互动"作为核心特性的推动因素
- **"我们不仅与其他游戏竞争，也与所有数字活动竞争"**——把社交媒体/消息应用视为扩展游戏生态的机会而非威胁
- URL: https://mp.weixin.qq.com/s/ViWblCqc6o68qDprrNalGQ
