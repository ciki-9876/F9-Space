# 一句话摘要

从格斗游戏BUG到暗黑2协同到神界元素反应，梳理出技能联动设计的5类方法论：连击（Combo）、取消（Cancel）、协同（Synergy）、反应（Reaction）、循环（Loop）。五者不独立而是可组合的设计工具集，好战斗=在五维度都埋了足够交互点让玩家自己发现。

# 关键观点（五大联动方法）

## 1. 连击（Combo）
- 核心：多个攻击动作在短时间内衔接，利用取消窗口/状态优势形成连续打击
- 10种品类各有逻辑：ACT（取消机制+评价条）、手游ARPG（换人接力）、格斗（帧数据+气槽）、战术竞技（猜拳克制）、动作射击（射击→处决→射击节奏）、类魂（体力条限制）、卡牌（能量利用率最大化）、MMO（固定优先级循环）、幸存者类（系统自动连招）、派对格斗（击飞+弹射）

## 2. 取消（Cancel）
- 核心：用新动作打断当前后摇，压缩出招时间窗口
- 4种类型：攻击取消攻击、技能取消攻击、闪避/跳跃取消、换人取消
- 设计目的：提升操作上限 + 让战斗更流畅 + 奖励精确输入

## 3. 协同（Synergy）
- 核心：A技能为B技能提供前置条件，改变B的运行方式（不是加数值，是改机制）
- 3种类型：状态递进（破防→倒地）、条件触发（特定状态下增伤/必暴/形变）、技能树协同（加点互相加成）
- 设计目的：鼓励组合 + 从"堆数值"转向"找配合" + 给辅助技能存在感
- **误区**：直接加属性的buff不算协同；必须改变技能的伤害计算/动作判定才算

## 4. 反应（Reaction）
- 核心：两种不同属性先后作用于同一目标，产生全新效果（A+B→C，C既不属于A也不属于B）
- 3种类型：元素反应（水+火→蒸发）、物理+属性反应、状态转化（油+火→火海）
- 设计目的：非线性互动 + 思考顺序和组合 + 改变战场环境
- **关键**：顺序往往重要（先毒后火=火海，先火后毒=毒被烧掉）
- **误区**：属性克制（倍率变化）≠ 反应（全新效果）

## 5. 循环（Loop）
- 核心：资源/效果闭环——上轮产出=下轮投入，形成"永动机"节奏
- 3种类型：能量循环（普攻→能量→技能→能量）、追击循环（反击→充能→技能→反击）、冷却循环（AB互减CD）
- 设计目的："永动机"输出节奏 + 鼓励构建完整BD + 高伤上限来源
- 案例：暗黑3旋风蛮（转→产怒→继续转）、星铁追击队（被打→反击→充能→大招→嘲讽→被打）

## 核心结论
- 五者不独立，是可组合的设计工具集
- 好战斗=在五维度都埋了足够交互点，让玩家自己去发现、组合、打破
- 玩家快感来自"我自己摸出来的连招"——不依赖外部奖励，来自"我做到了"

# 我认同的

- 作为战斗/技能设计的基础分类框架储备。五类分类清晰且有具体案例支撑。

# 我有疑问 / 不认同的

- **这套分类适用于"有战斗系统的游戏"，对非战斗型游戏需要类比迁移**：如果做休闲/模拟/解谜类独立游戏，这五类联动的概念需要抽象为"系统间的交互模式"而非字面的"技能联动"。→ **调用规则**：做战斗游戏时直接用；做非战斗游戏时抽象为"机制A如何影响机制B的运行方式"的通用框架。

## 通用原则

| 原则 | 落地动作 |
|---|---|
| 五维度都要有交互点 | 设计战斗时检查：连击/取消/协同/反应/循环每个维度是否都埋了至少一个机制 |
| 联动 = 玩家自己发现 | 不要把最优解写在教程里，让玩家通过实验发现组合——"我做到了"的快感 |
| 协同 ≠ buff | 真正的协同是改变技能运行方式，不是加数值 |
| 顺序创造深度 | 反应类机制加入"顺序重要"的设计，增加策略层 |
| 循环是高伤上限来源 | 但需要限制（衰减/上限）防止无限连破坏平衡 |

## 场景限定

| 触发条件 | 调用什么 |
|---|---|
| 设计技能树/配队系统 | 协同类型三种模式（状态递进/条件触发/技能树加成） |
| 设计元素/属性系统 | 反应类型（注意顺序设计+与属性克制区分） |
| 设计养成/BD系统 | 循环类型（资源闭环设计+永动机节奏） |
| 设计动作手感 | 连击+取消（帧数据/取消窗口/后摇管理） |
