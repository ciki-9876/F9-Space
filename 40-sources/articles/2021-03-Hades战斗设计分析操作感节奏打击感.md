# 一句话摘要

腾讯游戏策划对 2020 TGA 最佳动作游戏《Hades》的战斗系统专业拆解：操作感（冲刺为桥梁的无缝衔接）+ 战斗节奏（跑轰式高频攻防转换）+ 打击感（有限信息量内选择合适反馈）+ 技能体系（roguelike BUILD 构建）。核心：流畅爽快来自系统性设计而非单一亮点。

# 关键观点（4模块）

## 1. 操作感：冲刺为桥梁的流畅设计
- **冲刺优先级仅次于死亡**：任何状态都能冲刺=移动永远可用=流畅感基石
- **受击优先级低**：玩家在攻击/技能过程中几乎不被打断=操作不受阻
- 对比暗黑3：D3有大量控制打断移动，Hades给了玩家"不受阻的自由"
- **设计原则**：保证核心动作（移动）永远可执行，减少操作阻滞感

## 2. 战斗节奏：跑轰式高频攻防转换
- **情绪模型**：紧张累积（高频威胁/小窗口/多重威胁）→ 操作宣泄（高频攻击释放紧张）= 爽
- **作战窗口**：数量多（复数敌人保证永远有机会打）+ 时长短（逼迫快速决策）
- **攻防一体**：冲刺既是闪避又是突进，攻防转换在同一个按键内完成
- **战斗时长三特征**：短（单关<1分钟避免疲劳）、随流程成长（保持心流）、波动大（roguelike随机性）
- **设计原则**：用"多重/高频威胁"驱动攻防转换频率，用"高频操作"提供情绪出口

## 3. 打击感：有限信息量内的精准反馈
- **核心认知**：信息量有限——玩家能舒适接受的反馈量有上限，不是四维度全拉满就好
- **4个信息维度**：动作/镜头/特效/音效
- **4种体验目标**：拟真/夸张/临场/观察
- **Hades的选择**：服务于"高效刷图+快节奏跑轰"的核心乐趣，不追求所有维度极致
- **帧动画差异化武器体验**：大剑=停顿蓄力=力量感；长枪=残影缩帧=速度感；拳套=连贯画面=连打感
- **受击反馈=战斗信息**：破防(击飞+位移=有效打击) vs 未破防(震动=弱反馈=信息传达"无效")
- **设计原则**：在有限信息预算内，选择服务于核心玩法风格的反馈方式

## 4. 战斗时长公式
- `战斗时长 = 敌人有效生命 / 有效每单位时间输出`
- 短TTK(单怪<5秒) + 短关卡(<1分钟) = 爽快 + 避免跑轰疲劳
- 与 roguelike 策略选择形成"战斗操作→策略决策→战斗验证"循环

# 我认同的

- 作为战斗手感设计的专业参考。"冲刺优先级高于一切"和"信息量有限需要选择"两条是最有启发的设计原则。

# 我有疑问 / 不认同的

- **Hades 的"不受阻"设计是为 roguelike 快节奏服务的特定选择，不是通用最优解**：类魂游戏恰恰靠"受击打断"来制造紧张和惩罚，如果所有游戏都学 Hades 的"不打断"就会丢失挑战感。→ **调用规则**：这些设计选择都是为特定战斗风格服务的。设计战斗时先定风格（跑轰/类魂/策略），再从本文选择匹配该风格的具体手法。

# 应用映射(给未来 AI 看的应用指引)

> **调用时机**：当福九设计动作游戏的战斗手感/操作感/节奏时调用。

## 通用原则(任何动作游戏战斗设计都适用)

| 原则 | 落地动作 |
|---|---|
| 核心动作永远可执行 | 确定你的"冲刺等价物"（玩家最常用的动作），给它最高优先级 |
| 情绪=紧张累积+操作宣泄 | 威胁频率制造紧张，高频操作提供宣泄出口 |
| 信息量有限需要选择 | 不是所有反馈维度都拉满，选择服务于你核心风格的反馈 |
| 帧动画塑造武器差异 | 停顿=力量、缩帧=速度、连贯=流畅——用常识认知做差异化 |
| 受击反馈=战斗信息 | 不同受击表现（击飞vs震动）传达"有效/无效"的信息 |

## 场景限定

| 触发条件 | 调用什么 |
|---|---|
| 设计快节奏动作游戏（跑轰/roguelike/ACT） | 全套4模块方法论 |
| 设计打击感/武器差异化 | 帧动画处理+信息量预算+受击反馈分层 |
| 调整战斗节奏（太慢/太无聊） | 检查：作战窗口够多吗？威胁够频繁吗？TTK够短吗？ |

## 不适用场景

- 类魂/高惩罚型战斗（这类靠"受击打断"制造紧张，与Hades逻辑相反）
- 策略/回合制游戏（不涉及实时操作手感）
- 非战斗型游戏
