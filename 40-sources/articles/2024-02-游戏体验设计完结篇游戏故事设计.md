# 一句话摘要

基于"预测处理"认知模型构建的游戏体验设计理论：意识=预测+反馈的受控幻觉，游戏设计=欺骗大脑制造更真实的幻觉。核心工具：惊喜公式（喜欢=熟悉+意外）、交互的叙事优势（主动>被动=更深记忆）、峰终定律应用。附 Neil Gaiman 创意方法论。

# 关键观点

## 底层理论：预测处理模型
- **意识 = 对世界的预测+反馈**：大脑先预测，再通过互动反馈修正预测。"意识是受控的幻觉。"
- **游戏设计的本质**：利用人类简化模型的机制和偏差，让玩家产生更真实的幻觉+不断调动注意力持续体验
- 三个设计维度：交互过程（模拟真实）、反馈（调动预测处理系统）、记忆（形成个人叙事）

## 体验自我 vs 叙事自我
- **体验自我**：关注当下的感受→抓注意力的重点
- **叙事自我**：从经历中记住什么→峰终定律（高峰+开头结尾印象最深）
- 游戏体验 = 交互过程中的反馈（体验自我）→ 最终收获的情感/记忆/意义（叙事自我）

## 惊喜设计万能公式
- **喜欢 = 熟悉 + 意外**
- 打破常规公式：角色×场景×行为 的非常规组合
- 人本能追求确定性/安全感/具象化 → 在此基础上制造意外才有效

## 游戏叙事的独特优势：交互=主动=更深记忆
- 电影/视频 = 被动接受信息
- 游戏交互 = 主动行为 → 主动获取的反馈大脑更在意（预测处理原理）
- "游戏是一系列有意义**感**的选择"（对席德梅尔的迭代）
- 结论：尽量减少无法互动的纯播片环节，用交互推进叙事

## Neil Gaiman 创意方法论
- **翻转固定印象**：圣诞老人的故事 = 把"快乐送礼物"翻转为"被迫的永恒惩罚"
- **汇合（confluence）**：创意 = 已知事物的连接。把生活中现成事物变形/放大/缩小
- **从短篇练起**：想象力像肌肉靠训练习得，先把小船放下水
- **点子文学 = 高概念**：一个简短假设唤起好奇心。《坟场之书》= "如果孩子被幽灵抚养长大？"

# 我认同的

- 全部认同。"喜欢=熟悉+意外"和"交互=主动=更深记忆"作为游戏设计底层原理储备。Gaiman创意方法对我的创作天赋有直接加持。

# 我有疑问 / 不认同的

> 以下由 AI 基于福九处境预生成的反方种子，待审核：

- **"预测处理"是认知科学假说，不是已证实的定律**：用它指导设计可以，但不要把它当作"唯一正确的解释框架"。游戏好玩的原因可能比一个单一模型复杂得多。→ **调用规则**：作为"理解为什么某些设计有效"的思维工具使用，但不要用它排斥其他设计直觉。你的审美直觉可能比理论模型更快地找到好设计。

## 通用原则(任何游戏体验/叙事设计场景都适用)

| 原则 | 落地动作 |
|---|---|
| 喜欢 = 熟悉 + 意外 | 设计任何体验时：先建立熟悉感（让玩家知道规则），再制造意外（打破预期） |
| 交互 > 被动 | 能让玩家主动做的事不要用播片代替；主动获取的信息记忆更深 |
| 峰终定律 | 体验的高峰时刻和结尾决定记忆；把最好的放在高峰和结局 |
| 体验自我抓注意力，叙事自我留记忆 | 过程中用新鲜刺激维持注意力；结束时用情感/意义制造记忆 |
| 翻转固定印象 = 创意捷径 | 想创意时：拿一个熟悉事物，问"如果把它的某个属性反过来会怎样？" |
| 汇合 = 已知事物的连接 | 想设定时：把两三个不相干的已知事物组合在一起，看能否产生新意义 |

## 场景限定技巧(仅当触发条件匹配时调用)

| 触发条件 | 可调用的技巧 | 出处 |
|---|---|---|
| 设计游戏叙事/剧情 | 交互推进叙事（减少纯播片）+ 利用峰终定律安排高潮和结局 | 第二章 |
| 想游戏创意/世界观设定 | Gaiman 三招：翻转固定印象 + 汇合已知事物 + 从短篇（小原型）练起 | 3.1.2 |
| 分析"为什么这个设计有效" | 用预测处理模型：它是否成功欺骗了大脑？熟悉+意外是否平衡？ | 第一章 |
| 设计想要"出圈"的内容 | 快速抓注意力（少见元素）+ 持续新鲜+共鸣 + 深刻结尾 | 2.1 |
| Playtest 后玩家反馈"没感觉" | 检查：交互是否足够？被动接受太多？高峰时刻有没有？ | 交互叙事段 |

## 不适用场景

- 纯系统/数值设计问题（本文侧重体验/叙事层面，不涉及具体数值平衡）
- 需要具体关卡布局/Metrics 时（用三角洲那篇）
