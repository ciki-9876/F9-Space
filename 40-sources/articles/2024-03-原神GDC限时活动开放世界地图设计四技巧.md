# 一句话摘要

米哈游关卡设计师在 GDC 2024 分享《原神》夏季限时活动地图设计方法论：围绕"限时性"做情感设计（告别主题化）、利用活动激发探索（收集品承载叙事）、按阶段揭示隐藏区域（开放世界分段开放）、连接独立地图与主世界观（不做"填充物"）。

# 关键观点（四个设计技巧）

## 1. 围绕时间限制做情感设计——"告别"是设计机会不是遗憾
- 限时内容结束时玩家会产生离别情绪——这不是问题，是设计机会
- 把"告别"主题化为任务：大肉丸案例——第一周认识、中间陪伴、最后一周告别灵魂消散
- 叙事曲线反映玩家与活动的关系升华
- **通用原则**：活动结束阶段天然唤起情感，围绕这一时刻设计能激发社区讨论

## 2. 利用活动激发探索——收集品承载叙事
- 收集品不只是凑数换奖励，而是承载世界观碎片/环境谜题线索/故事背景
- "回声海螺"案例：32个海螺各有配音，引导玩家到特定地点触发新任务
- **通用原则**：在同时发布的活动之间建立有趣的内部联系，创造连贯体验

## 3. 按阶段揭示隐藏区域——分段开放制造惊喜
- 开放世界不一开始就完全开放，每个阶段同步推出新区域
- 关键：揭示方式本身要有戏剧性（岛屿从海中升起的过场动画）
- 与编剧合作精心编写故事来合理化地形的戏剧性变化
- **通用原则**：多阶段活动用令人惊讶的方式推出新内容

## 4. 连接独立地图与主地图——不做"填充物"
- 限时地图要与主世界观有内在传说联系
- "漫漫归乡路"案例：仙灵从活动地图回到主地图的蒙德城，暗示金苹果群岛是蒙德失踪的山
- 34%相关社区讨论围绕这个世界观连接展开
- **通用原则**：把限时活动编织到主要传说中→增加深度+引发社区讨论+提高参与度

## 教训：错误规划地图大小
- 1.6版本首周42%开箱率（流畅），但2.8版本因地图过大+玩法过于复杂，玩家消化不完
- 核心教训：限时内容的体量必须匹配有限的活动时长

# 我认同的

- 全部认同。四个技巧作为未来游戏设计参考储备，原则层面可降维应用到独立游戏/小团队场景。

# 我有疑问 / 不认同的

> 以下由 AI 基于福九处境预生成的反方种子，待审核：

- **这些技巧绑定"大型在线运营游戏+大团队+6周更新周期"的前提**：独立游戏如果做限时活动，不可能有"关卡设计团队+编剧+任务策划"配合精心编排。独立开发者做限时内容更可能是轻量版（如季节性小更新），需要将这些原则降维应用。→ **调用规则**：提取"情感设计"和"分段揭示"的原则层面，但不要照搬"多团队协作精心编排"的执行规模。

# 应用映射(给未来 AI 看的应用指引)

> **调用时机**：当福九设计游戏的限时内容/活动/DLC/赛季更新时调用。也适用于"如何让内容结束时留下好印象"的通用场景。

## 通用原则(任何游戏活动/限时内容设计都适用)

| 原则 | 落地动作 |
|---|---|
| 限时 = 情感设计机会 | 内容结束时玩家天然有情感，围绕"告别/纪念"设计任务或仪式 |
| 收集品承载叙事 | 不要做纯凑数的收集，每个收集品带一点故事/线索/世界观碎片 |
| 分段揭示制造惊喜 | 不一开始就全部开放，每个阶段用戏剧性方式揭示新内容 |
| 独立内容连接主线 | 限时/DLC/支线要与主世界观有内在联系，不做"填充物" |
| 体量匹配时长 | 限时内容的大小必须让玩家在有限时间内消化完 |

## 场景限定技巧(仅当触发条件匹配时调用)

| 触发条件 | 可调用的技巧 | 出处 |
|---|---|---|
| 设计限时活动的结局 | 围绕"告别"做情感设计：让玩家在活动中建立情感连接→结尾安排告别仪式 | 技巧一 |
| 设计收集品/成就系统 | 让收集品承载叙事（配音/文字/线索），引导玩家到特定地点触发内容 | 技巧二 |
| 设计多阶段发布的内容 | 每阶段用戏剧性方式揭示新区域/功能，揭示方式本身要有"wow moment" | 技巧三 |
| 做DLC/番外/独立关卡 | 确保与主线世界观有传说联系，不是孤立存在。玩家发现连接时会兴奋 | 技巧四 |

## 不适用场景

- 做无限时内容的游戏（永久在线的内容不需要"告别"设计）
- 极简/超休闲游戏（没有世界观深度支撑这些手法）
