# 设计启发(给产品设计参考)

- **核心洞察**: AI 工具越多,用户越需要一个自己可控的上下文层,而非每个工具各存一份
- **架构模式**: 多源提取 → 结构化文件(md) → 协议分发(MCP/导出)
- **与我知识库的关系**: 我的知识库本质上就是手动版 Context Vault;Unabyss 做的是自动化采集 + 标准化分发
- **产品化方向**: 如果千星奇域要做"创作者画像 → 多业务 agent 共享",可参考这个"采集-结构化-分发"三层架构
