# 筛选标准

## 留(满足任一)

- 我**主动想找过**至少一次,但没找到 ← 最强信号
- 改变过我某个判断或决策
- 包含一个我**至今还在用**的方法/工具/框架
- 涉及千星奇域 / UGC / 米哈游业务的**具体洞察**
- AI 对话产出的结论(尤其当时给我帮助过的)
- **产品推荐**: 产品解决了一个明确场景问题,未来我遇到该场景/开发类似功能时需要被提醒 → 入 `50-tools/`

## 丢(满足任一 → 99-archive 或直接删)

- "感觉不错"但说不出为什么留
- 工具类但 3 个月没用过
- 资讯类(新闻、行业动态、过期热点)
- 重复主题已经留了 3 篇以上 → 只留最好的 1 篇
- 收藏后从没回看过、且现在看也没共鸣

**判断不准就丢**。漏一两篇不影响,留太多反而稀释信号。

# 写笔记的格式

每条内容写一个 .md,从 `60-meta/templates/` 选模板:

| 内容性质 | 模板 | 放进 |
|---|---|---|
| 我的思考、结论 | insight.md | 30-insights/ |
| 别人的文章/视频精华 | source.md | 40-sources/articles/(or videos/) |
| AI 对话产出 | dialogue.md | 40-sources/dialogues/ |
| 工具/资源索引 | tools.md(可一文件多条) | 50-tools/ |

# 文件命名

格式: `YYYY-MM-中文关键词.md`

例:
- `2026-05-AI注意力经济.md`
- `2026-04-某up主-UGC生态3.0.md`
- `2026-05-Claude对话-注意力经济.md`

**用中文,不用拼音**(扣子搜中文更准)。

# tag 规则

- 必须从 [tag-schema.md](tag-schema.md) 选
- 领域 tag: 选 1-2 个
- 类型 tag: 选 1 个
- 工具 tag: 可选
- 词典外的新词 → 暂记到 tag-schema.md 底部"待审视"区,周末统一决定

# 处理流程

## 日常(看到新内容时)

1. 浏览器装 MarkDownload → 一键存为 .md → 落到 `00-inbox/`
2. **不立刻整理**,先攒着
3. 本周日清空 inbox

## 周日清 inbox(每周 30 分钟)

每条素材三选一:
- 按筛选标准**留** → 选模板写 .md → 放对应目录
- **不留** → 删除或进 `99-archive/`
- **当周来不及决定** → 加 `#待整理` tag,延到下周(最多再延 1 周,否则强制丢)

## 月底专题盘点(每月 1-2 小时)

选 1-2 个高价值话题(本月被反复触达的):
- 用 Claude Code 或扣子读 40-sources/ 全目录
- 综合给观点 → 你审稿、加判断、加私货
- 落到 `20-topics/`,文件名如 `2026-06-Q2-UGC内容中台调研.md`

# 时间盒(过往筛选阶段限定)

- **总时长**: 最多 4 周
- **每周**: ≤ 5 小时
- **截止日**: 2026-07-02 后强制切日常,未筛完的进 `99-archive/untouched/`

# 过往筛选范围(双轨第 1 周)

只筛**两类**,其他全部 archive 不看:

- **类 1**: 你**记得**、想找过的(像那篇 AI 与注意力经济)
  → 主动回忆,把脑子里有印象的捞出来
- **类 2**: 最近 3 个月的高频收藏(还热乎)
  → 按平台(微信收藏 / Notion / flomo)逐个过

5 年前的微信收藏不要碰,死亡陷阱。
